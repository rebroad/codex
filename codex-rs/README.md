# Codex CLI

[**Codex CLI Documentation**](https://developers.openai.com/codex/cli)

This repository publishes the Codex fork as `@rebroad/codex`.

## Installing Codex

Today, the easiest way to install Codex is via `npm`:

```shell
npm i -g @rebroad/codex
codex
```

You can also download the published release tarball from [rebroad/codex releases](https://github.com/rebroad/codex/releases).
